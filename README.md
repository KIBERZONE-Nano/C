Лабораторная работа: Обработка файлов в C++
Описание проекта
Проект реализует решение 6 задач по обработке бинарных и текстовых файлов на языке C++. Все задачи реализованы в виде статических методов одного класса FileTasks.

Цель работы
Освоение методов работы с различными типами файлов (бинарные, текстовые) в C++, включая операции чтения, записи и обработки структурированных данных.

Технические требования
Язык программирования: C++17 или выше
Компилятор: g++/clang++/MSVC с поддержкой стандартной библиотеки
Операционная система: любая (Windows/Linux/macOS)

Структура проекта
Класс FileTasks
Содержит все необходимые статические методы для генерации данных и решения задач:

1. Задание 1: Бинарные файлы
Методы:
generateBinaryFile1() - генерация бинарного файла со случайными числами
task1() - нахождение разности максимального и минимального элементов
Алгоритм: Линейное сканирование файла с поиском min/max значений

2. Задание 2: Бинарные файлы и матрицы
Методы:
generateBinaryFile2() - генерация данных для матрицы
task2() - копирование в матрицу и замена максимальных элементов
Алгоритм:
Чтение всех чисел в вектор
Определение размера квадратной матрицы
Заполнение матрицы с дополнением нулями
Замена максимальных элементов на 0

3. Задание 3: Бинарные файлы со структурами
Структура: Toy (название, цена, возрастные границы)
Методы:
generateBinaryFile3() - генерация файла со структурами
task3() - поиск наиболее дорогих игрушек
Алгоритм: Двухпроходная обработка с определением max цены и фильтрацией

4. Задание 4: Текстовые файлы
Методы:
generateTextFile4() - генерация файла с числами (по одному в строке)
task4() - подсчет вхождений максимального элемента
Алгоритм: Однопроходное чтение с обновлением max и счетчика

5. Задание 5: Текстовые файлы
Методы:
generateTextFile5() - генерация файла с числами (несколько в строке)
task5() - подсчет четных элементов
Алгоритм: Парсинг чисел из строк и проверка на четность

6. Задание 6: Текстовые файлы
Методы:
generateTextFile6() - генерация текстового файла
task6() - фильтрация строк по подстроке
Алгоритм: Построчное чтение и поиск подстроки методом find()

Сборка и запуск
1. Клонирование и компиляция
# Клонирование репозитория
git clone <repository-url>
cd file-processing-lab
# Компиляция программы
g++ -std=c++17 -o file_tasks main.cpp

2. Запуск программы
# Запуск всех задач последовательно
./file_tasks

3. Индивидуальный запуск задач
Программа может быть модифицирована для запуска отдельных задач:
int main() {
    // Запуск только задания 1
    FileTasks::generateBinaryFile1("data.bin", 10);
    FileTasks::task1("data.bin");
    
    return 0;
}

====== ВСЕ ЗАДАНИЯ ВЫПОЛНЕНЫ ======

Особенности реализации
1. Генерация случайных данных
Используется Mersenne Twister (mt19937) для качественной генерации
Для каждого типа данных свои распределения:
Целые числа: uniform_int_distribution
Вещественные числа: uniform_real_distribution
Строки: выбор из предопределенного набора

2. Обработка ошибок
Проверка успешности открытия файлов
Обработка пустых файлов
Корректное закрытие файловых потоков

3. Эффективность алгоритмов
Однопроходные алгоритмы там, где возможно
Оптимальное использование памяти
Минимальное количество операций ввода-вывода

4. Структура кода
Инкапсуляция логики в статические методы
Разделение генерации данных и их обработки
Переиспользование кода там, где это уместно

Тестирование
Тестовые данные
Пустые файлы - корректная обработка
Файлы с одним элементом - граничные случаи
Большие файлы (1000+ элементов) - проверка производительности
Специальные значения (минимальные/максимальные числа)

Валидация
Проверка корректности вычислений
Верификация выходных файлов
Сравнение с эталонными результатами

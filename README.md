Лабораторная работа: Класс Time на C++ с перегрузкой операторов

Общее описание
Данный проект представляет собой реализацию класса Time для работы с временем в 24-часовом формате на языке C++. Проект состоит из двух частей:
Базовый класс с конструкторами, методами и операцией вычитания
Расширение функциональности через перегрузку операторов
Проект демонстрирует основные принципы объектно-ориентированного программирования, работу с перегрузкой операторов и обработку исключительных ситуаций.

Техническое задание
Задание 1 (3 балла)

Реализовать класс Time со следующими требованиями:
Поля: short int hours, short int minutes
Конструкторы (не менее трех)
Перегрузка оператора вывода для вывода полей
Метод: вычитание переменной типа Time (с учетом перехода в предыдущие сутки)
Проверка корректности данных
Все исходные данные вводятся с клавиатуры

Задание 2 (5 баллов)
Добавить перегруженные операции к классу Time:
Унарные операции:
++ (добавление минуты)
-- (вычитание минуты)
Операции приведения типа:
Неявное приведение к int (количество минут)
Явное приведение к bool (true если время не 00:00)
Бинарные операции:
< (сравнение на основе количества минут)
> (сравнение на основе количества минут)

Реализация
Ключевые особенности реализации:
1. Класс Time содержит:
private:
short int hours;
short int minutes;  
void normalize();  // Приватный метод для нормализации времени
2. Конструкторы (3 вида):
Конструктор по умолчанию: Time()
Конструктор с параметрами: Time(short int h, short int m)
Конструктор копирования: Time(const Time& other)
3. Основные методы:
Time subtract(const Time& other) const - вычитание времени
Геттеры и сеттеры с проверкой корректности
Два метода для ввода: inputTime() и inputTimeFormatted()
4. Перегруженные операторы из задания 2:
Унарные:
Time& operator++();      // Префиксный ++
Time operator++(int);    // Постфиксный ++
Time& operator--();      // Префиксный --
Time operator--(int);    // Постфиксный --
Приведения типа:
operator int() const;           // Неявное приведение к int
explicit operator bool() const; // Явное приведение к bool
Бинарные операторы сравнения:
bool operator<(const Time& other) const;
bool operator>(const Time& other) const;
// Дополнительно реализованы: <=, >=, ==, !=
Оператор вывода:
friend std::ostream& operator<<(std::ostream& os, const Time& t);

 Компиляция и запуск
Требования:
Компилятор C++ с поддержкой стандарта C++11 или выше
Операционная система: Windows, Linux или macOS

g++ -std=c++11 -o time_program time.cpp

Тестирование:

Тесты, включенные в программу:
1. Тестирование конструкторов:
Конструктор по умолчанию (00:00)
Конструктор с параметрами
Конструктор копирования
Автоматическая нормализация (25:70 → 02:10)

2. Тестирование ввода данных:
Ввод в двух форматах: "часы минуты" и "HH:MM"
Проверка корректности данных (0-23 для часов, 0-59 для минут)
Обработка некорректного ввода

3. Тестирование метода вычитания:
Обычное вычитание (14:30 - 8:20 = 6:10)
Вычитание с переходом через полночь (8:00 - 9:30 = 22:30)
Вычитание равных значений (10:15 - 10:15 = 00:00)

4. Тестирование унарных операторов:
Префиксные и постфиксные ++/--
Переход через полночь (23:59++ → 00:00)
Переход через полночь в обратную сторону (00:00-- → 23:59)

5. Тестирование операций приведения типа:
Неявное приведение к int (2:30 → 150 минут)
Явное приведение к bool (00:00 → false, 00:01 → true)

6. Тестирование бинарных операторов сравнения:
Все операторы сравнения: <, >, <=, >=, ==, !=
Сравнение на основе общего количества минут

Примеры использования
Создание объектов:
Time t1;                    // 00:00
Time t2(14, 30);           // 14:30
Time t3(25, 70);           // 02:10 (автоматическая нормализация)
Time t4 = Time::inputTime("Введите время: "); // Ввод с клавиатуры

Вычитание времени:
Time t1(10, 45);
Time t2(8, 20);
Time result = t1.subtract(t2);  // 02:25

Time morning(8, 0);
Time late(9, 30);
Time diff = morning.subtract(late);  // 22:30 (переход через полночь)

Использование перегруженных операторов:
Time t(10, 30);
// Унарные операторы
++t;          // 10:31
t++;          // 10:32 (возвращает старое значение)
--t;          // 10:31
t--;          // 10:30 (возвращает старое значение)
// Приведение типа
int minutes = t;          // Неявное: 10:30 → 630 минут
bool isNotEmpty = static_cast<bool>(t);  // Явное: true
// Сравнение
Time t1(8, 30);
Time t2(14, 45);
if (t1 < t2) {  // true (510 < 885)
    cout << "t1 раньше t2" << endl;
}

Ввод с клавиатуры:
Программа поддерживает два формата ввода:
Введите первое время (часы и минуты через пробел): 14 30
Введите второе время (в формате HH:MM): 8:20

Особенности реализации
1. Автоматическая нормализация:
Метод normalize() автоматически корректирует значения:
Минуты ≥ 60 → добавляются к часам
Часы ≥ 24 → переход к следующим суткам
Отрицательные значения → переход к предыдущим суткам

2. Обработка ошибок ввода:
Проверка диапазонов значений
Очистка потока ввода после ошибок
Повторный запрос при некорректном вводе

3. Учет переходов через полночь:
Все операции корректно обрабатывают переходы через 00:00

4. Дружественный интерфейс:
Четкие сообщения об ошибках
Поддержка двух форматов ввода
Наглядный вывод результатов

🎯 Обзор проекта

Система управления мотопарком представляет собой консольное приложение для учета и управления парком мотоциклов. Программа реализует полный цикл работы с базой данных: добавление, удаление, сортировку, поиск и анализ данных.

Ключевые особенности:

Модульная архитектура с разделением интерфейса и реализации
Полное соответствие Stanford CodeStyle
Интуитивный пользовательский интерфейс
Расширенная статистика и аналитика
Обработка ошибок и валидация данных

🛠️ Сборка и запуск

Требования

Компилятор C++ с поддержкой C++11 (g++, clang++, MSVC)
Операционная система: macOS, Linux или Windows


Компиляция

macOS/Linux:
g++ -std=c++11 -o motopark_app motopark.cpp main.cpp

Windows (MinGW):
g++ -std=c++11 -o motopark_app.exe motopark.cpp main.cpp

Windows (Visual Studio):
cl /EHsc /std:c++11 motopark.cpp main.cpp

Запуск
./motopark_app        # macOS/Linux
motopark_app.exe      # Windows

class MotoDatabase {
private:
    std::vector<Motorcycle> motorcycles;  // Основной контейнер
    int nextId = 1;                      // Счетчик для генерации ID
    
public:
    // CRUD операции
    bool addMotorcycle(const Motorcycle& motorcycle);
    bool removeMotorcycle(int id);
    
    // Алгоритмы сортировки
    void sortByYear();
    void sortByEngineVolume();
    void sortByPrice();
    
    // Алгоритмы поиска
    Motorcycle* findMotorcycleById(int id);
    std::vector<Motorcycle> findMotorcyclesByBrand(...);
    
    // Аналитические функции
    double getAveragePrice() const;
    double getTotalValue() const;
};

Алгоритмы

Сортировка: Используется std::sort с лямбда-выражениями
Поиск: Линейный поиск с использованием std::find_if
Фильтрация: std::copy_if для выборки по критериям
Статистика: std::accumulate для агрегации данных
Обработка ошибок

Валидация входных данных (год, объем, цена)
Проверка уникальности ID
Обработка неверного пользовательского ввода
Защита от дублирования записей

bool MotoDatabase::saveToFile(const std::string& filename) {
    std::ofstream file(filename);
    if (!file.is_open()) return false;
    
    for (const auto& m : motorcycles) {
        file << m.id << "," << m.brand << "," << m.model << ","
             << m.year << "," << m.engineVolume << ","
             << m.price << "," << m.licensePlate << "\n";
    }
    
    file.close();
    return true;
}

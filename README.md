Лабораторная работа: Реализация классов HashSet, Dictionary и наследование
Описание проекта
Данный проект реализует три задания на языке C++ с использованием пользовательских классов:

Задание 1: Реализация класса MyHashSet для работы с неупорядоченным множеством уникальных элементов
Задание 2: Реализация класса MyDictionary для работы со словарем
Задание 3: Реализация иерархии классов с наследованием для работы с информацией о людях
Проект демонстрирует принципы объектно-ориентированного программирования, работу с шаблонами, управление памятью и XML-документирование кода.

Структура проекта
├── lab6.cpp              # Основной файл с реализацией всех классов и функций
├── sour_cream.txt        # Файл с тестовыми данными для задания 2
├── README.md             # Этот файл с описанием проекта

Технические требования
Компилятор C++ с поддержкой стандарта C++11 или выше
Операционная система: Windows/Linux/macOS
Сборка и запуск
Компиляция:
g++ -o lab6 lab6.cpp
Запуск:
./lab6

Описание заданий
Задание 1: Реализация класса MyHashSet
Цель: Создать класс, реализующий функционал неупорядоченного множества (HashSet) с уникальными элементами.

Реализованные методы:
Add(T item) - добавление элемента
Remove(T item) - удаление элемента
Contains(T item) - проверка наличия элемента
Union(MyHashSet other) - объединение множеств
Except(MyHashSet other) - разность множеств
Intersect(MyHashSet other) - пересечение множеств

Особенности реализации:
Внутреннее хранение в динамическом массиве
Автоматическое увеличение вместимости при необходимости
Элементы уникальны (дубликаты игнорируются)
Реализованы конструктор копирования и оператор присваивания

Задача: Анализ предпочтений в шоколаде среди сладкоежек. Определить, какие шоколадки нравятся всем, некоторым или никому.
Задание 2: Реализация класса MyDictionary
Цель: Создать класс, реализующий функционал словаря (ассоциативного массива).

Реализованные методы:
Add(K key, V value) - добавление пары ключ-значение
Remove(K key) - удаление по ключу
ContainsKey(K key) - проверка наличия ключа
Get(K key) - получение значения по ключу
Set(K key, V value) - установка значения по ключу
Особенности реализации:
Хэш-таблица с линейным пробированием
Автоматическое рехеширование при заполнении 70%
Уникальность ключей
Обработка коллизий

Задача: Мониторинг цен на сметану в магазинах. Определить для каждого вида сметаны (15%, 20%, 25%) количество магазинов, продающих ее по минимальной цене.
Задание 3: Наследование
Цель: Создать иерархию классов для представления информации о людях.

Классы:
Person (базовый класс):
Хранит имя человека
Виртуальные методы для работы с именем
PersonWithBirthday (производный класс):
Наследует от Person
Добавляет дату рождения
Методы для вычисления возраста и знака зодиака
Переопределенный метод PrintInfo()

Задача: Демонстрация работы с наследованием и полиморфизмом.
XML-документация

Все классы и методы снабжены XML-документацией в формате:
/// <summary>
/// Описание класса/метода
/// </summary>
/// <param name="param">Описание параметра</param>
/// <returns>Описание возвращаемого значения</returns>

Обработка ошибок: Использование исключений для обработки ошибок
Полиморфизм: Виртуальные методы и динамическое приведение типов
